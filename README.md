# 自动泊车演示客户端

这是一个基于 Electron 的简易停车场自动泊车演示程序。界面里有一个俯视停车场，小车会从入口出发，使用混合 A* 算法规划路径，自动倒车泊入你选中的车位，泊好后提示“停车已完成”。

停车场内部尺寸为 40m x 20m，提供三种真实布局，可在界面右上角切换：

- 垂直入库：80m x 40m 大型车库，中央有两道等长的纵向隔墙，隔墙两侧双面布置垂直车位，外围另有一圈梳齿状车位。
- 侧方停车：80m x 20m，模拟道路两侧平行泊车，车位首尾相接或仅留几厘米缝隙。
- 斜列车位：80m x 40m，四排紧凑鱼骨状斜列车位；相邻车位共享同一条斜向长边，
  中央区域同样布置车位。左侧入口保留 8m 转向缓冲带，避免车位贴墙导致车辆无法转弯。

程序在生成场地时会强制校验车位之间、障碍物之间以及两者之间互不重叠，出入口也不会被遮挡。

每张地图都是随机生成的：点击右侧的“新地图”会换一套车位数量、间距和障碍物位置，
地图编号会显示在侧栏。同一个地图编号总是复现同一张地图。

生成规则：

- 部分车位会停着其他车辆（显示为灰色车形），这些车位视为障碍物，不可选为目标；
  占用比例在 15%–80% 之间随机，用来模拟从空闲到停车高峰的不同时段。
- 每张地图都会保证至少有一个“已占用 + 空位 + 已占用”的夹击车位：两个已停车辆
  位于空位左右或前后，形成需要窄间隙操控的 worst case 泊车场景。
- 侧栏会显示“空闲 / 总数”，每次刷新空位比例都会变化。
- 生成器只保证布局符合现实：车位与障碍不重叠、不越界、不挡出入口，行车通道不被封死，
  并至少保留 4 个空位可选。
- 地图不保证每个空位都能停进去。苛刻的车位交给规划算法处理，规划失败会提示换一个车位，
  这正是用来检验规划能力的地方。

## 运行

```bash
npm install
npm run dev
```

## 打包 Windows 程序

```bash
npm run build:win
```

打包结果在 `release/` 目录，可以双击安装使用。

## 测试

```bash
npm test
```

## 操作方式

1. 把鼠标移到车位 P 上，车位会高亮。
2. 点击车位，程序开始规划路径并自动泊车。
3. 可以随时点“重新开始”，或切换 0.5x / 1x / 2x 播放速度。

如果一次规划失败，小车会先略微倒车，再重新规划，最多重试 3 次。
